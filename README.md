# Pokémon Card Photobooth Project

Transforming users into custom Pokémon cards where they can personalize their name, health points (HP), and unique attacks.

## Overview
This photobooth application captures an image of the user, integrates it into a custom Pokémon card template, and provides an interactive interface for editing card statistics such as name, HP, and attack moves before printing or saving.

## Features
- **Live Capture:** Take a photo directly within the web interface.
- **Card Customization:** Edit card metadata including:
  - Trainer/Pokémon Name
  - Health Points (HP)
  - Custom Attack Names and Damage Values
- **Dynamic Preview:** Real-time preview of the customized Pokémon card layout.
- **Export & Print:** Save the final creation as an image file or send it to a connected printer.
